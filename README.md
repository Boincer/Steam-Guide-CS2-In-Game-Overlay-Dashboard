Das ultimative CS2 In-Game Overlay Dashboard (HTML-Startseite)
Willst du dein Steam-Overlay im Spiel nützlicher machen? Mit dieser  HTML-Startseite hast du alle wichtigen CS2-Tools, Matchmaking-Plattformen und den aktuellen Map-Pool für Premium Wettkampf mit nur einem Tastendruck (Shift + Tab) sofort im Blick ohne das Spiel zu minimieren.

Vorteile des Dashboards:
- Schneller Zugriff auf Google direkt im Spiel
- Direktlinks zu FACEIT, CSREP.GG und der Steam Community
- Visuelle Übersicht des aktuellen Map-Pools für Premium Wettkämpfe
- Vollständig responsives Design: Passt sich automatisch perfekt an deine In-Game-Auflösung an (egal ob 16:9, 16:10 oder 4:3 stretched)
- Extrem ressourcenschonend, da es eine lokale HTML-Datei ist
 
Schritt 1: Den GitHub link nutzen "https://boincer.github.io/Steam-Guide-CS2-In-Game-Overlay-Dashboard/" oder!

Die HTML-Datei vorbereiten
Zuerst benötigst du den Code für das Dashboard. ().
Speichere die Datei am besten an einem Ort auf deinem PC, an dem du sie nicht versehentlich löschst, zum Beispiel unter:
C:\CS2_Dashboard\startseite.html

Schritt 2: Als Startseite im Steam-Overlay einrichten
1. Öffne Steam und starte Counter-Strike 2.
2. Drücke im Spiel die Tastenkombination Shift + Tab, um das Steam-Overlay zu öffnen.
3. Klicke ganz unten in der Leiste auf das Webbrowser-Symbol (Weltkugel), um den In-Game-Browser zu öffnen.
4. Klicke im Browser oben auf das Zahnrad-Symbol (Einstellungen).
5. Trage im Feld für die Startseite den Pfad zu deiner lokalen Datei ein.
Wichtig: Der Pfad muss im Browser-Format eingegeben werden. Wenn deine Datei auf Laufwerk C: im Ordner „CS2_Dashboard“ liegt, lautet die Adresse:
file:///C:/CS2_Dashboard/startseite.html
1. Bestätige die Eingabe und klicke auf das Home-Symbol im Browser, um zu testen, ob die Seite korrekt geladen wird.

!!Profi-Tipp für die Nutzung:

Klicke die Links auf dem Dashboard am besten mit dem Mausrad (mittlere Maustaste) an. Dadurch öffnen sich FACEIT, Google und Co. automatisch in einem neuen Tab im Hintergrund. So bleibt dein Haupt-Dashboard immer offen und du verlierst nie die Übersicht!
